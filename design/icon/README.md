# 아이콘 원본

로고의 서명에서 첫 글자만 남긴 흑백 표식이다. 도장의 빨강은 쓰지 않는다.
탭에 놓이는 16픽셀에서는 색보다 획이 먼저 사라지기 때문이다.

글자는 Mrs Saint Delafield(SIL OFL 1.1)의 `L`을 외곽선으로 떠서 넣었다.
글꼴이 없는 곳에서도 같은 모양이 나오도록 글자가 아니라 도형으로 박아 두었다.
획이 얇아 그대로는 작은 크기에서 끊어지므로, 같은 외곽선을 같은 잉크로
덧그려(`stroke`) 펜으로 그은 굵기를 만든다. 그 굵기를 크기마다 달리한 것이
아래 네 파일이다.

| 파일 | 덧그린 굵기 | 쓰는 자리 |
| --- | --- | --- |
| `mark-small.svg` | 52 | 16 · 32 |
| `mark-mid.svg` | 38 | 48 · 64 |
| `mark-512.svg` | 26 | 128 · 256, 그 위 |
| `mark-apple.svg` | 30 | 홈 화면 180 (여백을 더 준다) |

`public/favicon.ico` 한 파일에 16 · 32 · 48 · 64 · 128 · 256을 담고, 각
크기를 위 표대로 따로 그려 넣었다. 큰 그림 하나를 줄이기만 하면 획이 1픽셀
아래로 내려가 회색 얼룩이 된다.

바탕은 언제나 흰 종이다. 어두운 탭에서도 흰 종이 조각으로 보이는 편이,
잉크만 남아 배경에 묻히는 것보다 이 서비스에 맞다.

고쳐 그린 뒤에는 크기별로 다시 뽑아 `favicon.ico`와 `apple-icon.png`를
새로 만든다. 만드는 법은 `scripts/build-icon.md`에 적어 두었다.
