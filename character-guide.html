ChatGPT에 그대로 붙여넣어 캐릭터를 뽑는 순서입니다. 그림 세 장만 나오면 나머지 움직임은 코드가 만듭니다.

00

먼저 알아둘 것

걷고, 고개를 돌리고, 폴짝 뛰는 동작은 그림을 여러 장 그려서 만들지 않습니다. 한 장을 CSS로 기울이고 튕기고 좌우로 뒤집어서 만듭니다. 그래서 실제로 필요한 그림은 자세 세 개뿐입니다.

파일자세언제 보이나
ledger-idle.png 가만히 서 있는 모습 평소. 걷는 것도 이 그림으로 만듭니다
ledger-talk.png 한 손을 들어 가리키는 모습 기능을 설명할 때
ledger-sleep.png 웅크려 자는 모습 한동안 아무것도 안 할 때

셋은 같은 캐릭터여야 합니다. 색이 달라지거나 머리 크기가 바뀌면 화면에서 자세가 바뀔 때마다 다른 인형으로 갈아끼운 것처럼 보입니다. 그래서 한 대화 안에서 이어서 만드는 것이 중요합니다. 02에서 다룹니다.

프롬프트는 영어로 적어 두었습니다. low-poly, flat shading 같은 말은 영어 쪽이 훨씬 정확하게 먹힙니다. ChatGPT에는 한국어로 말을 걸어도 프롬프트만 영어면 됩니다.

01

어떤 캐릭터로 갈지 고르기

셋 중 하나만 고르세요. 아래 프롬프트에서 [캐릭터] 자리에 넣을 문장입니다. 고민되면 첫 번째가 가장 무난합니다.

02

첫 장 만들기

ChatGPT를 열고 아래를 붙여넣습니다. [캐릭터] 자리에 01에서 고른 문장을 넣으세요.

prompt 1 — idle 
Create a game asset image.

Subject: [캐릭터]

Style:
- low-poly 3D, PlayStation 1 / Nintendo 64 era, roughly 300 visible triangles
- flat shading with hard polygon edges, no smooth shading, no subdivision
- slightly chunky proportions, big head, short limbs, readable at small size
- soft neutral studio lighting from the upper left, one soft contact shadow
- muted palette, no neon, no gradients across the whole body

Framing:
- full body, standing upright, weight on both feet
- three-quarter view, facing slightly to the right
- centered, with a small margin of empty space on all four sides
- square image, 1024 x 1024

Background:
- fully transparent PNG, no background, no ground plane, no backdrop
- if transparency is not possible, use a flat solid #00B140 green background
  with no shadows or gradients on it

Do not add: text, watermark, logo, UI elements, borders, multiple views,
turnaround sheets, or any other character.

배경이 투명으로 안 나오면 초록 배경으로 다시 요청하세요. 초록은 나중에 빼기 쉽습니다. 흰 배경은 캐릭터의 흰 부분까지 같이 지워져서 가장 나쁩니다.

마음에 드는 게 나올 때까지 몇 번 다시 뽑아도 됩니다. "머리를 조금 더 크게", "조끼 색을 진하게" 처럼 한국어로 고쳐 달라고 해도 됩니다. 이 대화창을 닫지 마세요. 다음 단계가 여기서 이어집니다.

03

같은 캐릭터로 두 장 더

첫 장이 마음에 들면, 같은 대화창에서 이어서 아래 둘을 차례로 붙여넣습니다. 새 대화를 열면 다른 캐릭터가 나옵니다.

prompt 2 — talk 
Same character, exactly the same model, colors, proportions and style
as the image above. Do not redesign it.

Change only the pose: it is now raising one arm and pointing forward,
head tilted slightly up, as if explaining something.

Keep everything else identical: same three-quarter view, same camera angle,
same lighting direction, same scale within the frame, same transparent
(or #00B140 green) background, same 1024 x 1024 square.
prompt 3 — sleep 
Same character again, exactly the same model, colors, proportions and style.
Do not redesign it.

Change only the pose: it is now curled up asleep on the ground,
eyes closed as two small curved lines, body low and compact.

Keep everything else identical: same lighting direction, same transparent
(or #00B140 green) background, same 1024 x 1024 square.
The character may occupy less vertical space since it is lying down —
keep it centered horizontally.

셋을 나란히 놓고 봤을 때 같은 인형의 사진 세 장처럼 보이면 성공입니다. 색이 튀거나 비율이 달라졌으면 그 한 장만 다시 뽑으세요.

04

내려받아 넘겨주기

  1. 세 장을 각각 PNG로 내려받습니다. JPG는 배경이 투명해지지 않으니 안 됩니다.
  2. 파일 이름을 정확히 이렇게 바꿉니다.
    ledger-idle.png · ledger-talk.png · ledger-sleep.png
  3. 대화창에 세 장을 그대로 올려 주세요. 배경 빼기와 크기 맞추기는 제가 합니다.

초록 배경으로 받았다면 그대로 주셔도 됩니다. 빼서 다듬는 건 이쪽에서 처리합니다. 작게 줄여도 각진 면이 뭉개지지 않는지도 같이 확인하겠습니다.

캐릭터를 붙인 다음에 기능을 얹습니다. 어느 화면에서 무엇을 설명할지는 화면이 다 만들어진 뒤에 정하는 편이 낫습니다 — 지금 정해 두면 화면이 바뀔 때마다 말도 같이 틀어집니다.

05

잘 안 나올 때

증상고치는 말
너무 매끈하고 요즘 3D 같다 harder polygon edges, fewer triangles, no smooth shading, make it look like a 1998 video game model
작게 줄이면 뭉개진다 simplify the silhouette, remove small details, make the shape readable at 100 pixels tall
배경이 계속 붙어 나온다 flat solid #00B140 green background only, no shadow on the background, no floor, no gradient
자세를 바꾸랬더니 캐릭터가 달라졌다 use the exact same model as the previous image, only change the pose — 그래도 안 되면 첫 이미지를 다시 첨부해서 요청
여러 각도를 한 장에 그려 준다 one single view only, not a turnaround sheet
프롬프트에 적힌 #00B140은 방송용 크로마키 초록입니다. 캐릭터에 초록을 쓰는 디자인을 골랐다면 #FF00FF 자홍으로 바꿔 쓰세요.
